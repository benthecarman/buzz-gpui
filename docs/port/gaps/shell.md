# Gap audit: app shell, navigation, panels, shortcuts, updates, presence, notifications, native side

Reference: `/home/ben/projects/buzz-app` (paths below are relative to it).
Port: `/home/ben/projects/buzz-gpui` main checkout (paths prefixed `gpui:`).
Only gaps are listed in the tables. DONE items are counted at the end.

Port architecture note: the port has no plugin runtime. Pages are a fixed enum
(`gpui:crates/app/src/ui/sidebar.rs:13-18`: Messages, Agents, Settings), so
contribution registries (pages, panels, account actions, settings cards) have
no direct equivalent. Rows that exist only because of the plugin runtime are
listed under "Webview / plugin-runtime only" at the end, not as gaps.
