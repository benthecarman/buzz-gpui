# Parity audit: plugin system, bundled plugins and misc features

Scope: buzz-app's plugin system (`src/plugins`), the bundled plugins that the
messages/composer, channels/relay, agents/sessions/terminal and settings/shell
audits do not cover, `src/features/{browser,projects,workflows,channel-templates,updates,developer}`,
and the native modules `src-tauri/src/browser*`, the updater, `managed_npm.rs` and
`enterprise_*`.

Revisions: buzz-app `/home/ben/projects/buzz-app` (main checkout), buzz-gpui
`/home/ben/projects/buzz-gpui` (main checkout, worktrees ignored).

## How "enabled by default" is decided in buzz-app

There are two default lists. They agree:

- Browser/dev catalog: `src/bundled/index.ts:60-200`, the `enabledByDefault` flag
  on each `BundledPlugin` entry.
- Native desktop catalog (the one packaged builds use):
  `crates/plugin-manager/src/lib.rs:229-258` (`enabled_by_default`). New bundles
  must opt in. Bundles that are missing from this list are off: Todos, Templates &
  teams and Bestie.
- Saved per-plugin overrides win over defaults. `buzz.channels` is forced on
  (`src/plugins/storage.ts:49-51`). Policy text: `docs/plugin-architecture.md:210-240`.
- Not in either catalog: `src/bundled/link-lab` (only in the fixture
  `/tests/fixtures/link-lab.html`) and `src/bundled/composer/lab` (only in the gallery fixtures).

## Port overview (why most rows are MISSING)

The port has three pages, fixed in an enum: Messages, Agents and Settings
(`crates/app/src/ui/sidebar.rs:13-19`). The page-row area of the sidebar
has one hard-coded "Agents" row (`sidebar.rs:197-206`). The header shows "Me" and
"Messages" tabs, but the "Me" tab has no click handler and no page
(`crates/app/src/ui/workspace.rs:383-387`). Settings has Profile, Custom emoji,
Communities, Appearance, Notifications, Shortcuts, Agents and About
(`crates/app/src/ui/settings/mod.rs:45-66`). It has no Plugins, Updates or
plugin-contributed cards. The port has no module registry, no contribution
points and no per-module enable flags. Every feature is wired by hand.

Context: the project's recorded scope decision of 2026-10-09 deferred workflows,
projects/GitHub, Builderlab, moderation, templates, todos, voice notes, browser,
pairing and Inbox/Reminders. `docs/port/relay.md:132` marks workflow kinds out of
scope. `docs/port/relay.md:323-325` marks `enterprise_login_gate` optional. The
port's goal is now one-to-one parity, so these items are listed as gaps.
